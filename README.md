# 🛍️ Customer Segmentation & Marketing Analytics

An end-to-end machine learning project that discovers customer groups from purchasing behaviour and provides an interactive **Streamlit dashboard** for exploring segments and predicting the segment of individual or bulk customers.

The project combines **unsupervised learning** to discover customer segments with a **Random Forest classifier** that learns to reproduce those segment assignments for convenient predictions.

> **Important:** The segment labels are generated by K-Means. They are pseudo-labels, not real campaign-response outcomes. Model accuracy measures agreement with the K-Means assignments—not whether a customer will respond to a marketing campaign.

---

## ✨ Features

- **Customer data exploration** — inspect data types, missing values, duplicates, distributions, and summary statistics.
- **Data cleaning & feature engineering** — prepare customer records and derive age, customer tenure, total spending, and total purchases.
- **Exploratory data analysis (EDA)** — visualize customer characteristics and purchasing behaviour.
- **Customer segmentation with K-Means** — compare candidate cluster counts using the elbow method and silhouette scores.
- **Segment interpretation** — profile clusters using business-friendly measures such as income, spending, purchases, and customer activity.
- **Model training and evaluation** — train a Random Forest classifier with a preprocessing pipeline and `GridSearchCV`.
- **Interactive Streamlit app** — predict one customer's segment, inspect segment profiles, and upload a file for batch predictions.
- **Downloadable results** — export batch predictions as a CSV file.

### Why use both K-Means and Random Forest?

- **K-Means** discovers groups in the customer data without requiring pre-existing target labels.
- **Random Forest** learns to predict the cluster assignments from the original customer features, making it practical to score new customers through the app.
- The saved classifier includes its fitted preprocessing steps, so the app can pass raw model features through the same imputation, scaling, and encoding workflow used during training.

## 🖥️ Streamlit App

The app includes three tabs:

| Tab | What it does |
|---|---|
| 🔮 **Predict a customer** | Enter customer demographics, activity, spending, and purchase-channel details to receive a predicted segment and model confidence. |
| 📊 **Segment profiles** | Explore the number of customers in each segment, average characteristics, and compare metrics across segments. |
| 📁 **Batch prediction** | Upload a customer CSV, predict segments for multiple rows, review the results, and download the output CSV. |

The dashboard also displays a short interpretation of each segment, with names assigned according to average total spending. These labels are descriptive shortcuts; they are not independently validated business categories.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/youssefeldawey0/Customer-Segmentation-Marketing-Analytics-ML-project.git
cd YOUR-REPOSITORY
```

Replace the URL and repository directory with your own GitHub repository details.

### 2. Create a virtual environment

**Windows (PowerShell):**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, you can use Command Prompt instead:

```bat
.venv\Scripts\activate.bat
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Run the Streamlit app

Make sure `cluster_classifier.pkl` is present beside `app.py`, then run:

```bash
streamlit run app.py
```

Streamlit will print a local URL (usually `http://localhost:8501`) that you can open in your browser.

## 📓 Re-running the Machine Learning Pipeline

To reproduce the analysis or regenerate the model files:

1. Open `Marketing_Campaign_ML_Pipeline (2).ipynb` in VS Code or Jupyter Notebook.
2. Ensure `marketing_campaign (1).csv` is in the same directory as the notebook.
3. Run the notebook cells **from top to bottom**.
4. Review the EDA, clustering evaluation, segment profiles, and classifier evaluation.
5. Confirm that `cluster_classifier.pkl` has been regenerated. The notebook also writes `cluster_classifier.joblib` and `cluster_profiles.csv`; these are git-ignored, so they will only exist locally and won't appear in commits.

The dataset is read as a tab-separated file by the notebook, so preserve its original format when loading it there.

## 📥 Input Data for Batch Predictions

The batch-prediction tab expects a CSV, TSV, or TXT file with the same **raw columns** as the original customer dataset. Required columns include:

- Customer demographics and registration details: `Year_Birth`, `Dt_Customer`, `Income`, `Education`, `Marital_Status`, `Kidhome`, `Teenhome`
- Customer activity: `Recency`, `NumWebVisitsMonth`
- Spending: `MntWines`, `MntFruits`, `MntMeatProducts`, `MntFishProducts`, `MntSweetProducts`, `MntGoldProds`
- Purchases: `NumDealsPurchases`, `NumWebPurchases`, `NumCatalogPurchases`, `NumStorePurchases`

The app calculates `Age`, `Tenure_Days`, `Total_Spending`, and `Total_Purchases` before prediction. It uses the fixed historical reference date stored in the model bundle so that tenure is calculated consistently with training.

After prediction, the app adds a `Segment` column and lets you download the scored data as `segmented_customers.csv`.

## 📊 Evaluation & Responsible Interpretation

- The notebook separates training and test data before fitting preprocessing, PCA, and K-Means.
- Candidate cluster counts are evaluated using the elbow method and silhouette scores.
- `GridSearchCV` selects Random Forest settings using cross-validation on the training data.
- The classifier's test accuracy compares its predictions with K-Means-generated labels on held-out customers.

**Keep in mind:** high classifier accuracy means the model can reproduce the discovered clusters. It does **not** prove that the clusters improve campaign performance or predict real customer responses. Business usefulness should be validated against an appropriate real-world outcome before using these segments to make marketing decisions.
